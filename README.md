## Week 4 End
- This week I moved from Python into core Statistics, covering the full "Statistics Essentials" module. I started with the basics — descriptive vs inferential statistics, population vs sample, and key terms like variable, parameter, and statistic — along with data types (nominal, ordinal, discrete, continuous) and sampling methods (probability vs non-probability, with techniques like stratified, cluster, and systematic sampling). From there I went into measures of central tendency (mean, median, mode) and spread (range, quartiles, IQR, variance, standard deviation), followed by distributions — normal distribution, skewness, kurtosis, Z-scores, and the Central Limit Theorem. I also learned distance and relationship metrics like Euclidean/Manhattan distance, covariance, and correlation. The module wrapped up with hypothesis testing: null vs alternate hypotheses, p-values, Type I/II errors, and parametric/non-parametric tests like t-tests, Z-tests, and ANOVA, along with their real-world use in feature selection and model evaluation.
